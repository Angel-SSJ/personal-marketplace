# Design System

Self-contained five-skill design system engineering suite covering end-to-end W3C DTCG 2025.10 creation, cascade updates, perceptual OKLCH harmonies and palette philosophies (`Tonal Palette`, `Carbon (IBM)`, `Radix Colors`), dual-gate accessibility auditing (`WCAG 2.2 AA + APCA` / `WCAG 2.2 AAA + APCA Enhanced`), layer-by-layer structural auditing, and modular token-pure HTML component showcases.

## Included Skills

- **`/design-system-create`** (`skills/design-system-create/SKILL.md`): End-to-end design system creation with mandatory foundation gates and W3C DTCG 2025.10 + `DESIGN.md` + `DESIGN.html` deliverables.
- **`/design-system-update`** (`skills/design-system-update/SKILL.md`): End-to-end or selective layer updates with cascade propagation and pre-persistence accessibility regression blocking.
- **`/accessibility-audit`** (`skills/accessibility-audit/SKILL.md`): Read-only dual-gate WCAG 2.2 + APCA `0.0.98G-4g` accessibility auditing.
- **`/design-system-audit`** (`skills/design-system-audit/SKILL.md`): Read-only layer-by-layer and cross-layer design system auditing across all 9 layers and components.
- **`/component-design`** (`skills/component-design/SKILL.md`): Token-pure HTML5 component showcase creation across sizes, visual hierarchies, interactive states, and Light/Dark themes.
